# 栖页 LeafReader 1.1.10

原生 Android 阅读器，使用 Kotlin、Jetpack Compose 和 Android 原生文字排版。支持兼容 BookHub 契约的获授权服务和已核实的公开书源，不包含后端、预置账号或内置书籍内容。

## 本版（1.1.10）

- 设置去掉不可点击的「离线下载」标题，改为两个独立开关：「加书后自动下载」「仅在不计费 Wi-Fi 下自动下载」。后一项默认开启，总开关关闭时置灰但保留选择。升级保留 1.1.9 的自动下载总开关，缺少新偏好时仍采用原来严格网络规则。
- 只有总开关开启且用户明确关闭网络限制，自动下载才可使用移动数据、计费 Wi-Fi 或其他在线网络。限制开启时仍要求实际不计费 Wi-Fi。BookHub 及独立书源都按最新策略设置系统约束，并在传输/发布前检查，已有自动待办重新调度、旧执行失效；不重复入队、不回扫旧书架。手动下载保留独立的单次 Wi-Fi/流量选择。
- 不改变书架、进度、会话、书源、正文解析、简体显示或纸张。保留 1.1.9 的书源弹窗安全布局。策略与测试边界见 [自动下载网络设置](docs/AUTOMATIC_NETWORK_SETTINGS.md)。

## 延续 1.1.9 的修复

- 修复 BookHub 登录/编辑地址、OPDS/Legado 管理与添加/导入弹窗的操作区安全布局。窗口明确交由 Compose 处理系统栏/键盘，安全区取并集，Android 12+ 同时读取物理圆角。中间内容独立滚动，底部操作固定且可随字号增高；极矮键盘视口将关闭移到底部，保留操作空间。无需重新配置已有来源。
- 本次不改变书源、下载、简体转换、阅读进度、会话或数据格式。保持同包名与数据布局；可选编译默认值只接受本机输入，无参数构建没有真实 BookHub 地址。仓库不提供签名材料。
- 验证范围与设备限制见 [书源弹窗安全布局](docs/SOURCE_DIALOG_SAFETY.md)。

## 延续 1.1.8 的功能

- 全部来源的书名、作者、简介、目录、章节名和原生正文统一简体显示，无需开关。使用固定 OpenCC 离线词组/字典，不联网转换、不修改原始字段、书籍/章节 ID、源文件、下载副本或进度；编辑中的地址、规则、凭据与输入保持原样。图片保持原图，不 OCR。真实古登堡繁体正文与官方原生转换器逐字对照、旧字符锚点和断网冷启动验证见后文。
- 只有查询成功返回真正空页时才有界尝试另一种简繁拼写，保留原查询、实际命中的查询和原分页游标；不把错误、已在架过滤或未完分页当成无结果。古登堡本机目录仍支持两种拼写匹配同一书号，同标题同作者不同书号分别保留。
- 设置书源分为 BookHub、古登堡计划、OPDS 订阅、Legado 书源四个统一行入口。OPDS 与 Legado 分别管理已配置来源及添加/导入，不混排；设置页仍从安装包读取版本。
- 自动下载改为全局，默认仅在不计费 Wi-Fi 下对明确新加入的、支持并已确认保留权的书籍排队。覆盖 BookHub、古登堡、OPDS 与基础规则来源，不补扫已有书架，不替用户登录、不改变来源限速/容量限制；未知、不支持的后台来源不强行启动。旧版 BookHub-only 启用状态不能代表全局许可，升级后全局自动下载默认关闭，旧自动待办停止，已有内容、进度、会话和手动任务保留；用户主动开启后才处理之后新加的书。
- 独立来源自动待办保存本机，交由 Android JobScheduler 网络/存储约束择机运行；严格模式额外检查实际 Wi-Fi 与不计费能力，单一独立源任务串行并共享原请求限速。临时网络失败退避重试，权限/规则错误保留明确失败；暂停、重启和清理用稳定身份与 nonce 隔离。手动下载继续可主动选择流量，关闭自动下载不关闭手动下载。Android 调度时间由系统决定，不保证立即完成。
- 设置汇总本机全部书源缓存文件字节：包括各 BookHub 账号、公开源、隐藏项、历史版本、部分下载与缩图；只在 IO 统计文件长度，不打开账号/书名或逐本 SHA 检查，不含 APK/词典、偏好和 Keystore。退出 BookHub 仍能看到本机总计；日常操作留在单本更多，不新增集中任务列表。
- 阅读底栏保留「几/几 · 12.34%」：百分比从原算法的实际比例保留两位，未知为「—」，未完成不四舍五入成 100.00%。整数计算、是否按章节估算、原始锚点和同步协议不变；两位小数不表示新增全书篇幅信息。
- 在书源中并列 BookHub、古登堡计划、OPDS 订阅与导入的基础规则来源。BookHub 使用原账号；古登堡无需登录，找书页可选源、浏览中文书目或按书名/作者片段检索。切换找书来源不退出 BookHub，不触发登录书架差异比较。
- 所有已加入书籍保存在同一个本机书架，身份与进度包含来源；公开书仅在本机加入/移出，不写入 BookHub。已上架书会从可添加结果中隐藏。
- 设置可选择本地 JSON 或主动粘贴导入 Legado 基础声明式规则，找书选择该来源后走搜索、详情、目录、原生正文与按章离线续读。仅支持 CSS / 简单 JSON 路径、UTF-8 GET；不执行 JS/WebView/登录，不导入 Cookie/账户/凭据，不内置小说源。混合导入保留有效项，非兼容项按来源、字段与原因列出；目标为安卓版现代嵌套规则 JSON，详情见 [基础规则与限制](docs/LEGADO_BASIC.md)。
- 新增真正的 OPDS 1 订阅：设置 → 书源 → OPDS 订阅 → 添加 OPDS 订阅，填入自己的公开/自有免登录 HTTPS 目录并确认离线保留权。支持导航、发现的 OpenSearch、服务端 next 分页、同域 EPUB/封面获取和冷启动离线续读。已核实的公开示例 Wolne Lektury 可填入，仍需用户主动添加；不支持账号、Cookie、借阅/购买或跨域获取。详见 [OPDS 记录](docs/OPDS_SUBSCRIPTIONS.md)。
- 古登堡中文找书不再等待联网目录：随应用仅带 443 项书号、书名、作者的元数据快照（2026-11-25），不带正文、封面或离线样书。首次安装/断网即可搜索、浏览，支持常见简繁字和孔子、曹雪芹等常见作者别名；原书标题和 ID 不改。本机结果标注快照来源。已有较新机读目录仍优先，用户找书时过期目录在后台至多每日尝试一次更新，成功后七天内复用，失败保留本机书目，不把故障当空目录。官方 OPDS 的 503 / Retry-After 21600 不绕过、不频繁重试，中文入口保持同项目官方 CSV 后备。
- 古登堡/OPDS 书第一次阅读或明确下载时才取得完整 EPUB，校验后保存应用私有/no-backup 目录；保留封面、正文、图片和原书许可文件。完整副本无需 BookHub 会话即可离线重开。书架封面优先来自已有 EPUB 的明确封面标记，否则从该书官方元数据声明的单封面加载，不为缩图下载整本。
- 设置底部新增「版本」一行，读取安装包 versionName，不硬编码，不新增关于页。
- 原生阅读保持 EPUB 实际 spine 资源顺序；显示封面和正文，不执行脚本、加载外链或使用 WebView。不支持加密/固定版式、非 UTF-8 正文及超过安全限制的包。没有把文件名或任意插图猜成封面。
- 公开源手动下载复用 Wi-Fi/流量选择；阅读按需取书属于用户主动联网阅读。明确开启全局自动下载后，支持的公开源新加书会按当前网络设置进入后台队列；旧书架不回扫。中断未完成的公开源下载可再次主动发起，未完整的内容不会标成完整缓存。
- 清除下载同时清该书进度，移出同时清本机副本和进度；持久代次隔离迟到下载。没有改 BookHub 存储路径、加密身份、签名、同步协议或纸张/玻璃材质。没有内置未经核实的小说源。

本次仅同步公开源码，不附 APK，不创建 tag 或 Release。已有服务配置、会话、书架、进度和离线副本的存储布局保留；自行构建的签名限制见下文。

## 书架、书源和离线

一个本机书架显示已保存的各来源书籍，登录失效、退出、换源或重启不替换整个列表。身份仍包含原服务、账号和稳定书籍 ID；同名、同 ID 不跨来源合并。保留最近阅读排序、真封面缩图、下拉刷新、找书过滤与原位置续读。

有效的同源同账号 BookHub 登录下，明确加入/移出书架会同步名单；临时冲突或网络失败保存新版单本待办，读取最新状态/修订后有界重试。日检与下次正常登录只处理这些待办，不巡查整座书架、不补发旧隐藏或未登录操作，也不代替用户执行登录差异的批量选择。真正失效的授权暂停，等待正常登录或既有官方会话刷新，不保存密码或后台反复登录。

**清除下载会清除该书缓存和阅读进度，保留书架；明确移出会同时清本机下载与进度。** 旧响应和下载写入通过代次/nonce 隔离。服务端拉到的名单移出只更新可见名单，不静默销毁本机副本和进度。未登录操作保持本机范围，重新登录不会静默批量上传旧删除。

BookHub 完整缓存按所选内容版本核验，原账号有效的可恢复本地会话仍在且未收到明确读取拒绝时，可纯本地读取目录、正文和图片，不依赖服务在线。文件齐全不代表永久离线许可；退出、会话无法恢复或明确授权拒绝后需恢复原授权，副本不会因掉登录自动删除。不把旧书请求发给新服务。设置汇总本机全部书源缓存字节；既有已移出 BookHub 副本清理仍按当前授权账号隔离，日常操作放在单本更多。

中文原生分页支持字号、行距、段距、独立边距、纸张主题、图文页面、目录跳转和字符锚点续读。失败切章可返回刚才可读页，真实授权失效除外；失效历史提供目录和显式恢复。进度与下载保存在本机，不承诺云进度同步。

## 配置服务与升级

源码默认**没有真实 BookHub 服务器值**；古登堡公开渠道地址为本版正式内置来源。在“设置 → 书源 → BookHub”填写自己管理或获准使用的 HTTPS 地址、对应账号密码并确认读取授权。密码仅发送到明确选定的精确 HTTPS origin，不跨域转发、不保存；会话由设备 Keystore 加密。不同后端版本可能需要适配。

应用 ID 为 `app.leafreader`，versionName 为 `1.1.10`，versionCode 为 `1110`。无参数构建没有私有默认地址；设备已保存的地址和会话优先。存储路径、既有键与 Keystore 标识保留。自行构建通常使用构建者自己的签名，不能覆盖已安装的同包名 APK；已有用户不要为试源码而卸载，可用独立模拟器或测试机。合成升级回归不等于实际设备覆盖安装。

## 从源码构建

需要 JDK 17、Android SDK Platform 35、Build Tools 35.0.0。Gradle Wrapper 8.9，AGP 8.7.3，Kotlin/Compose Compiler 2.0.21；首次构建需要官方依赖仓库。

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk
export PATH="$JAVA_HOME/bin:$ANDROID_HOME/platform-tools:$PATH"
./gradlew testDebugUnitTest testReleaseUnitTest lintDebug lintRelease assembleDebug assembleRelease
```

Windows 使用 `gradlew.bat`。源码 release 默认未签名，使用自己的签名流程；官方发布证书私钥不在仓库中。自行构建通常不能覆盖已安装的官方同包名 APK，版本号增加不能解决签名不同。请用独立模拟器或测试机，不要为试源码而卸载现有应用。

可选本机输入 `LEAFREADER_DEFAULT_BOOKHUB_ORIGIN` 仅在生成任务执行时读取，不包含任何真实值或示例真实地址。无输入仍为手填 HTTPS。仅接受无凭据、路径、query 或 fragment 的 HTTPS origin，错误不回显输入；设备已保存的地址和会话优先。带值构建须在无 Git 的隔离目录，使用独立临时 Gradle 用户目录，并加 `--no-configuration-cache --no-build-cache -Pkotlin.incremental=false -Pkotlin.compiler.execution.strategy=in-process`；不用 debug 日志或 Build Scan，不运行会记录目标的 UI 测试，编译后移除临时生成区。带值 APK 的地址可提取，不能公开发布。公开 Release 不设置此输入。

## 验证范围

业务和 UI 回归使用自写书目、图片、协议夹具、`.invalid` 地址和本地 MockWebServer，不使用真实账号或用户图书。合成升级夹具和可复现 AES 测试键不用于真实设备 Keystore。正式 App 不内置样书或新增导入入口。
