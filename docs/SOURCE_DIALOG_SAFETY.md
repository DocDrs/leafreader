# 1.1.9 书源弹窗安全布局

设置的 BookHub、古登堡计划、OPDS 订阅、Legado 书源仍是四个独立入口，已有配置不迁移、不重写。古登堡直接切换到找书；OPDS/Legado 的已配置项也切换到找书，没有新增不必要的详情弹窗。

## 修改

- BookHub 登录/编辑目标、OPDS/Legado 管理、OPDS 添加及 Legado 导入共用全窗口布局。明确关闭平台 decor fitting，并让 Compose 统一处理系统栏、切口、IME 安全区的并集，不叠加重复键盘留白。
- 固定底部操作区；表单/来源列表独立滚动。操作按钮使用最小高度而不是固定高度，大字号可换行增高。BookHub 详情阅读按钮也取消固定高度。中间内容不会在底部操作区下绘制。
- Compose UI 1.7.6 在 Android 12+ 没有自动修改 dialog 的输入调整模式；本机旧版探针实际得到 ADJUST_PAN。因此明确采用 Android 12+ ADJUST_NOTHING，旧系统 ADJUST_RESIZE，与 Compose 窗口 inset 策略一致，避免平台平移和表单 IME padding 同时发生。没有升级整个 Compose 依赖。
- 极矮的键盘/横屏视口里，关闭按钮移到底部与主操作并排，去掉固定页眉以给滚动内容留空间。普通视口保留原有页眉风格。关闭和主操作有独立触控区域及无障碍语义，系统返回仍可用于关闭。
- Android 12+ 从本弹窗窗口读取四角 RoundedCorner 半径并随窗口布局更新，和系统/IME insets 取并集；左右另留 20dp、操作区上下留 8dp。早期系统没有圆角 API 时沿用保守内容边距和系统安全区。未设置系统手势排除区。
- 使用当前浅/深主题的系统栏图标对比。没有触碰登录、地址确认、权限、规则、下载、同步、阅读或存储逻辑。

## 可复现检查

通过实际 ReaderApp 的设置入口进入四个来源，并用主机原生 Android / Compose 测试的坐标触摸点击管理/添加/导入/确认/关闭。验证 BookHub 目标确认、OPDS 添加、Legado 导入实际生效，已有配置及原字符进度仍保留。另从古登堡找书结果进入书籍详情，滚动并触摸阅读按钮。

覆盖 Android 14/15、360×640dp、320×480dp、640×320dp、最高 2 倍系统字号、浅/深主题、底部三键/手势栏、左右横屏导航区、IME 弹起/收起及表单草稿保留。系统栏/键盘尺寸用 WindowInsetsCompat 可重复注入，检查底部主操作位于可用矩形、至少 48dp 高，再发坐标触摸并验证动作结果，不只调用无障碍 click。

截图是原生主机渲染；合成安全区没有真实键盘按键，也不能代替设备输入法动画。圆角半径计算有合成回归，但没有非零物理圆角设备。环境没有 Android 模拟器或 /dev/kvm，未实测真实手机/模拟器的导航、输入法、窗口动画及 pm install -r。无真实 BookHub 登录或远端账号操作。签名及版本兼容验证不等于实机升级测试。
