# 简体显示与全局自动下载（1.1.8）

显示层使用 OpenCC ver.1.1.9 / commit `556ed22496d650bd0b13b6c163be9814637970ae`，官方 https://github.com/BYVoid/OpenCC 。TSPhrases + TSCharacters 按词组最长匹配、再字符默认候选；STPhrases + STCharacters 仅用于成功空检索的拼写后备。原字典未修改，Apache-2.0 及 AUTHORS 同附；没有执行或打包 OpenCC 的原生程序。转换器为本项目纯 Kotlin 实现，4391 条繁转简词条与自写长文本的输出散列已对照官方原生 1.1.9。

原 Book/Chapter/源配置、文件和 ID 保持原始值；Compose 文本边界和 NativeReaderView 投影转换显示。投影保存每个显示 UTF-16 边界对应的原始边界，补充字符不切开代理对。原始位置用于持久化、目录/图像锚点及进度分子分母；StaticLayout 用显示文字，换版式重排回到原始位置所在页。图像位置作为转换边界，图片不改变。词典当前词条保持码点数，但可能改变 UTF-16 长度；测试覆盖实际此情形及受控扩展/收缩映射。该功能是汉字书写转换，不是语言翻译，也不归一化英文、标点、全角字母或段落。

检索至多使用原输入、简体、标准繁体三个不同拼写。仅首个成功页没有书籍、导航项和后页时才尝试后备；有结果时不混排多组结果，游标继续搭配实际成功查询。服务端自己的分词、匹配和可见书目范围仍由来源决定，不承诺额外绕过访问范围或覆盖所有一简多繁歧义。

全局开关新 key `global-auto-download-v1`；旧 BookHub-only 授权迁移为关闭，旧自动待办停止，手动任务、文件与阅读进度保留。开启时不扫描已有书架；只由成功新加书的事件创建请求，未知后台能力默认拒绝。BookHub 继续使用原账号队列，公开/基础规则来源使用独立持久队列，绝不传 BookHub 会话。独立源队列只有源 ID/书 ID/nonce/状态，不含密码、令牌、Cookie 或原始 URL。来源与文件锁、请求限速跨 UI/JobService 实例共享。

JobScheduler 的 UNMETERED 只是初筛；下载前及传输中仍检查实际不计费 Wi-Fi、意图 nonce、清理标记。丢网时不切流量；同一待办退避重试。只有解析/校验成功且必要本机内容存在，才由来源状态报告完整缓存。清除/移出先失效队列和写入代次再清文件；迟到响应不得恢复文件。普通取消保留已存内容及进度；清除/移出仍沿用用户选择的同时清该书进度规则。手动流量选择独立，不因全局开关关闭而失效。

全局占用仅汇总专用离线/缩图目录文件逻辑字节，含各来源、账号、历史、部分与临时文件；不解析账号/书名，不统计 APK/偏好/Keystore，不遍历符号链接。未登录也可统计总值，具体内容访问及隐藏项清理仍保持原授权隔离。

验证为合成资料、受控 HTTP、Robolectric 原生绘制与单独的真实公开《論語》本地检查；没有手机/模拟器安装、真实 BookHub 账号、真实 Android 后台运行时长或设备 GPU 实测。源码自行构建通常用自己的证书，不能覆盖既有官方同包 APK；不要卸载现有应用来试源码。
