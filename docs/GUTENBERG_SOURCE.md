# 古登堡来源核验（2026-11-25）

## 官方依据

- [官方离线目录与 OPDS 文档](https://www.gutenberg.org/ebooks/offline_catalogs.html)：XML OPDS 起点是 `https://www.gutenberg.org/ebooks/search.opds/`。官方声明 OPDS2 尚在测试、需联系获取，预计 2027 年停止 XML 入口；本客户端不猜测试地址。
- [官方机器人访问规则](https://www.gutenberg.org/policy/robot_access.html)：不抓取主站人类浏览页面。使用明确提供的机读目录和公开镜像；不全站轮询，不下载整座书库。
- [官方镜像说明](https://dev.gutenberg.org/help/mirroring.html) 列出 `gutenberg.pglaf.org`。该镜像 HTTPS 的 `/README` 明确说明 `cache/epub/` 是下游使用的生成内容目录；实际跟随根目录 → cache → epub → feeds 验证了 CSV。
- [OPDS 1.2 规范](https://specs.opds.io/opds-1.2)：Atom 采集条目、获取关系、next、OpenSearch。仅实现本来源需要的无账号子集，不声称通用认证目录或所有 OPDS 功能完备。

## 实际渠道与字段

| 用途 | 实际访问 | 数据/处理 |
|---|---|---|
| OPDS | 官方文档给出的 `https://www.gutenberg.org/ebooks/search.opds/` | 此次实际 503 维护页，`Retry-After: 21600`。停止重试；不得把夹具当成线上连通。 |
| 机读目录 | `https://gutenberg.pglaf.org/cache/epub/feeds/pg_catalog.csv.gz` | 实际 200，5,602,458 字节。字段 Text#, Type, Issued, Title, Language, Authors, Subjects, LoCC, Bookshelves。只保留 Type=Text、Language 含 zh；本次 443 项含中文的文字书目（435 项纯中文、8 项双语）。首次由用户找书触发，缓存中文元数据，本机 20 项分页，标题/作者片段搜索；不是全站搜索轮询。 |
| 每书元数据 | 镜像 `/cache/epub/{数字书号}/pg{数字书号}.rdf` | 核对 ebook 身份、dcterms:rights 及明确的小封面文件。仅允许所选书号的官方资源路径；只接受明确的 Public domain in the USA. 许可声明。 |
| EPUB 获取 | 所选书号镜像目录中实际声明的 `.epub` 链接 | 优先图片 EPUB3，其次图片 EPUB，再次其他 EPUB；不猜书源私有接口、不访问主站获取格式。只跟随精确官方 HTTPS origin，不跟随重定向或跨站链接。 |
| 封面 | EPUB OPF 的 cover-image/cover 标记；否则 RDF 明确单封面 | 不误用正文插图、不执行 SVG/脚本或为缩图下载整本。内存缩图约 2 MB 上限，磁盘缩图尺寸不超过 180×270。 |

镜像文件保留原许可及署名。古登堡的公版认定基于美国法律，用户仍需遵守所在地法律。客户端没有获得或宣称对全部国家、全部条目的普遍授权；没有将图书再分发到交付包。

## 隔离与离线

公开源稳定命名空间为 `gutenberg-public-v1`，书号为 `pg:<数字>`；与 BookHub origin/account 命名空间分离。没有账号、密码、令牌或 Cookie 参数，不接收 BookHub 会话，也不向 BookHub 写公开书架操作。

EPUB 在应用 no-backup 私有目录中按书号保存，完整 SHA-256 标记绑定整包版本；书内 dc:identifier 与选中书号一致才接受。压缩包不解压到任意路径，限制 ZIP 项数、单项和总解压大小，校验 CRC，拒绝越界/重复路径、加密、未声明或外部图像；不执行脚本。安全范围为压缩包最多 32 MB、单项 8 MB、总解压 32 MB、4096 文件；每章至多 8 张位图、总解码像素 800 万。图片仅限原生位图；SVG 仅提取指向已声明本地位图的引用。

目录按 OPF spine 的实际阅读资源排列，不根据文件名编造章节或删掉封面/许可页。正文字符锚点与版本绑定。此版尚未实现任意 EPUB 的复杂 TOC fragment 细分；BookHub 的原有解析不受影响。

完整且校验匹配的公开副本可独立离线阅读，冷启动无需 BookHub 或网络。清除同时清本书进度；移出清副本并本机隐藏。清理代次先持久化，迟到下载不得重建完整标记；其他来源和账号不受影响。中断未完成的公开下载不会冒充完整，用户可以再次明确发起。

## 真实验证与夹具边界

- 实际官方中文书：論語，书号 23839。镜像 EPUB 为 87,768 字节，SHA-256 `06f880e0e1b1479edc1387e82ae2ad312565853a58598a4b328a4bf8376f59d6`。原生界面可显示真实封面与正文；实际 EPUB 有三个 spine 资源（封面、正文、许可）。重建客户端后断网恢复同一章节与字符锚点，HTTP 尝试为零。
- OPDS 的采集/搜索/分页是合成协议回归，当前官方入口维护使该路径未能线上验通；可用目录走上述同项目官方镜像，不将二者混同。
- 账号隔离、BookHub 同步/续读及升级使用合成账号/存储。没有真实 BookHub 登录、写入用户书架或设备实装。交付预览仅含自写书目、图片和正文；原书、封面及本机实测材料排除。

## 1.1.5 首次找书修复

1.1.4 首次中文检索先等待官方 OPDS，再等待 5,602,458 字节 CSV 完成，且此前无本机书目。连接和单次读取有超时，但慢速持续响应可能延长整个请求；简体搜索也不会匹配繁体标题。这能重现长时间加载机制，不能据此断言用户手机的具体网络故障。

1.1.5 随包的 `assets/gutenberg-zh-catalog.json` 是同一份已校验官方 CSV 中 Type=Text、Language 含 zh 的 443 项书目事实，42,182 字节，只含 ID/书名/作者/空描述及来源日期，不含正文/封面/摘要。图书内容和许可仍在明确阅读/下载时核验。书目事实来自官方开放的离线机读目录，保留官方来源与日期，不增加 Project Gutenberg 商标或声称官方背书。

中文入口默认先本机搜索，不等 OPDS；过期 CSV 更新独立运行，限制总读取时间并保留后备，每日最多尝试一次；有效目录七天复用。搜索无匹配和目录缺失/损坏分别处理；后备结果以「本机中文书目」标注，不声称已查询到最新在线目录。常见简繁字折叠仅用于搜索，原始标题、服务身份、书号和阅读锚点保持不变。中文作者别名为明确有限映射，完整拼音/繁简转换不在本版范围。

验证：无磁盘目录、断网、永不返回的更新、超时异常、损坏磁盘目录、冷重建、更新退避、443 项本机分页；ReaderApp 实际找书输入与 IME 路径测试。真实设备的移动网络/DNS/代理环境未实测。
